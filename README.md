# rytglobal-accessibility-audit
This repository documents a full accessibility audit and remediation of rytglobal.com, a corporate training site I co-built, evaluated against WCAG 2.1/2.2 AA. Testing combined automated scanning — axe DevTools, Chrome Lighthouse, and WAVE — with manual keyboard navigation and NVDA screen reader testing, to catch what automated tools alone miss. Across five pages and the site's shared lead-capture form, the average accessibility score (WAVE's AIM score) improved from 4.8/10 to 9.5/10, a 97% increase, achieved by tracing each issue to its root cause in the source code rather than patching individual scanner flags one by one.

Full report — root-cause analysis, before/after screenshots, and code diffs — here: ./RYT-Global-Accessibility-Audit-Report.pdf
